# Security Policy

This repository contains the Rayls documentation. If you find a security issue in the
**documentation itself** (for example, an example that leaks a real secret, or guidance that
would lead an operator into an insecure configuration), please report it privately.

## Reporting

**Please do not report security issues through public GitHub issues or pull requests.**

Report privately through **GitHub's private vulnerability reporting**:

1. Open the [Security tab](https://github.com/raylsnetwork/rayls-sovereign-docs-internal/security) of this repository.
2. Click **"Report a vulnerability"** and complete the advisory form.

If you are unable to use GitHub's private reporting, contact a maintainer via the
[Rayls Network Discord](https://discord.com/channels/1252990258514235544/1252996402942836857).

Vulnerabilities in the Rayls **software** (not the docs) should be reported against the
relevant component's repository, following that repository's `SECURITY.md`.

## Disclosure

We treat all reports as confidential and ask that you not publicly disclose details until any
affected content has been corrected.
